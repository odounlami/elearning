# 2. Conception

Le parcours principal est :

1. consulter le catalogue ;
2. ouvrir une formation ;
3. s'inscrire à la formation ;
4. accéder au lecteur ;
5. terminer les modules ;
6. retrouver la progression dans la bibliothèque.

L'accès au lecteur est protégé par authentification. L'accès aux médias est également lié à l'inscription à la formation.
