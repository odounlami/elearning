# 1. Analyse du besoin

Le besoin est une mini plateforme permettant à un utilisateur de créer un compte, se connecter, consulter des formations, accéder à leurs modules et suivre sa progression.

Le périmètre obligatoire a été priorisé avant les bonus : authentification, catalogue, détail, lecture, doublage multilingue simulé, progression et tableau de bord.

Les critères de livraison ajoutent trois contraintes importantes : tests pertinents, lancement avec Docker Compose et documentation du cycle de développement.
