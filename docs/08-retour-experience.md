# 8. Retour d'expérience

Le principal arbitrage a été de terminer les fonctionnalités obligatoires avant les bonus. Cela a permis de conserver une architecture simple tout en couvrant le parcours utilisateur complet.

Le doublage multilingue est simulé avec deux pistes audio, conformément à la consigne. Les fonctionnalités bonus pourront être ajoutées ultérieurement sans être nécessaires à la livraison de cette version.

La prochaine étape après validation locale est le déploiement et une dernière vérification du parcours complet.
