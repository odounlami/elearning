# 4. Développement

Le développement a été organisé par fonctionnalités : authentification, catalogue, inscription aux formations, lecteur, progression, sécurité des médias, puis conteneurisation.

Le code est organisé par responsabilités : `core` pour les services et mécanismes transverses, `shared` pour les modèles et composants réutilisables, `pages` pour les écrans métier.

Le périmètre a volontairement été limité aux exigences principales du sujet afin de privilégier une livraison complète et testable.
